# Snapshot and extraction budgets

Extraction accepts per-call `maxNodes`, `maxChars`, `maxDepth`, `maxMetadataChars` and `maxDerivedChars`. Defaults are 4,000 nodes, 262,144 UTF-16 code units, 128 levels, 8,192 metadata characters and 8,388,608 derived heading/link characters. Each accepts a positive safe integer. A budget overrun fails the whole extraction rather than returning a partial record. Selector resolution consumes the node budget independently. The renderer captures the document in memory before the existing artifact output path, which may impose its own quota.

The snapshot implementation accepts `maxNodes`, `maxRecords`, `maxChars` and `maxFrames`, with defaults 2,000, 100, 12,000 bytes and 32. Each accepts a positive safe integer, except `maxChars` must be at least 512. Node limits apply per frame. Omitted content remains reported and old snapshot references are invalidated. The public `browser_snapshot` tool forwards these budgets. Output is bounded in UTF-8 JSON bytes, not characters.

Large caller-selected budgets can exhaust browser or host memory, exceed platform string or transport limits, or make a single renderer task unresponsive. Snapshot records retain live element handles. Cancellation relies on the existing session guard; it cannot interrupt synchronous renderer execution immediately. Neither tool paginates a live traversal.

Snapshot reference identity uses caller-controlled `identityNameChars` (default 240), `identityTextChars` (500), `identityNodes` (200), `identityAncestors` (128), `identityFrameDepth` (32), `identityMetadataChars` (1,024) and `identityLabels` (16). Each accepts a positive safe integer. Name, text and metadata sizes use UTF-16 code units; node budgets apply per name traversal, ancestor budgets to each visibility chain, and frame depth to the embedding chain. `maxScopeNodes` defaults to 20,000 for complex selector preflight and is also configurable. Increase the relevant budget and `maxChars` together when complete names do not fit. An incomplete identity never receives a reference; over-budget subtrees and frame-ancestry omissions are reported. Each retained reference stores its capture budgets and validates the complete fingerprint and visibility using the same budgets; later mutation or an incomplete validation fails closed.

Display-only text and form values still clip at 240 characters, with clipping reported; title and URL presentation have separate bounds. Budgets do not make the approximate name/role algorithm equivalent to the browser accessibility tree. Large identity budgets increase synchronous renderer work and retained fingerprint memory; they do not provide immediate renderer cancellation. Explicit scopes and DOM/eval remain useful for details, and page mutation between captures can change results.
